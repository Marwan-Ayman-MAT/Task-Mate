## 🚀 خطوات البدء السريع

### الخطوة 1️⃣: إعداد قاعدة البيانات

**مهم جداً! يجب القيام بهذه الخطوة أولاً**

1. افتح [Supabase Dashboard](https://app.supabase.com)
2. اذهب إلى **SQL Editor**
3. افتح الملف `/supabase/migrations/setup.sql`
4. انسخ **كل** الكود SQL
5. الصقه في SQL Editor
6. اضغط **Run**

✅ سيتم إنشاء:
- جدول `tasks` للمهام
- جدول `categories` للتصنيفات
- Row Level Security للحماية
- Indexes للأداء الأفضل

### الخطوة 2️⃣: تشغيل التطبيق محلياً (اختياري)

إذا أردت تجربة التطبيق على جهازك:

```bash
# 1. حمل جميع الملفات إلى مجلد
# 2. افتح Terminal في المجلد
# 3. نفذ الأوامر التالية:

npm install        # تثبيت Dependencies
npm run dev        # تشغيل التطبيق
```

ثم افتح المتصفح على: `http://localhost:5173`

### الخطوة 3️⃣: نشر التطبيق على الإنترنت

**الطريقة الأسهل: Vercel**

1. ارفع الكود إلى GitHub:
   ```bash
   git init
   git add .
   git commit -m "TaskMate App"
   git push
   ```

2. اذهب إلى [vercel.com](https://vercel.com)
3. اضغط "Import Project"
4. اختر repository الخاص بك
5. اضغط "Deploy"
6. انتظر دقيقة... تم! 🎉

سيكون التطبيق متاحاً على رابط مثل:
`https://taskmate-xxxxx.vercel.app`

بعد نشر التطبيق أو تشغيله محلياً:

## 🔧 استكشاف الأخطاء

### مشكلة: "Failed to load data"
✅ **الحل:**
- تأكد من تطبيق SQL Schema في Supabase
- تحقق من RLS Policies

### مشكلة: "Unauthorized"
✅ **الحل:**
- امسح localStorage من المتصفح
- سجل خروج ثم دخول مرة أخرى

### مشكلة: المهام لا تُحفظ
✅ **الحل:**
- افتح Console في المتصفح (F12)
- ابحث عن رسائل خطأ
- تأكد من اتصالك بالإنترنت

### مشكلة: شاشة بيضاء فارغة
✅ **الحل:**
- تأكد من رفع جميع الملفات
- افتح Console وتحقق من الأخطاء
- جرب إعادة بناء المشروع: `npm run build`
