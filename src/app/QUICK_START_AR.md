# 🚀 دليل البدء السريع - TaskMate

## ⚡ 3 خطوات فقط للتشغيل!

### 📥 الخطوة 1: حمل المشروع
اضغط على **"Download Project"** في أعلى اليمين ← سيتم تحميل ملف ZIP

### 📂 الخطوة 2: فك الضغط وافتح Terminal
```bash
cd taskmate
```

### 🎯 الخطوة 3: ثبت وشغل
```bash
npm install
npm run dev
```

**🎉 تم! افتح المتصفح على:** `http://localhost:5173`

---

## 📱 استخدام التطبيق:

### 1. **إنشاء حساب**
- افتح التطبيق
- اضغط "Sign up"
- أدخل البيانات وسجل

### 2. **إضافة مهمة**
- اضغط زر "+" الأزرق
- اكتب المهمة
- اختر التاريخ والتصنيف (اختياري)
- احفظ

### 3. **الفلترة والبحث**
- **على الموبايل**: اضغط أيقونة الفلتر
- **على الكمبيوتر**: استخدم الشريط الجانبي
- ابحث عن مهام محددة

---

## 🌐 رفع التطبيق على الإنترنت (مجاناً):

### الطريقة الأسهل - Netlify:

1. **سجل على** [netlify.com](https://netlify.com)
2. **في Terminal اكتب:**
   ```bash
   npm run build
   ```
3. **اسحب مجلد `dist`** إلى موقع Netlify
4. **تطبيقك شغال الآن على رابط مجاني!** 🎊

## 🆘 مشاكل شائعة وحلولها:

### ❌ خطأ: "Command not found: npm"
**الحل:** ثبت Node.js من [nodejs.org](https://nodejs.org)

### ❌ خطأ: "Port 5173 in use"
**الحل:**
```bash
npm run dev -- --port 3000
```

### ❌ خطأ في التسجيل/تسجيل الدخول
**الحل:** تأكد من الإنترنت شغال

## 📊 معلومات تقنية:

- **Framework**: React 18 + TypeScript
- **Styling**: Tailwind CSS v4
- **Database**: Supabase (PostgreSQL)
- **Drag & Drop**: react-dnd
- **Icons**: Lucide React
- **Build Tool**: Vite
