# ⚡ دليل البدء السريع - TaskMate

## 🎯 ما هو TaskMate؟

تطبيق **كامل الوظائف** لإدارة المهام مع:
- ✅ قاعدة بيانات حقيقية (Supabase PostgreSQL)
- ✅ نظام تسجيل دخول آمن
- ✅ مزامنة فورية بين الأجهزة
- ✅ تصميم داكن/فاتح احترافي
- ✅ واجهة متجاوبة (Desktop, Tablet, Mobile)

---

## 🚀 البدء في 3 خطوات

### الخطوة 1: إعداد قاعدة البيانات (5 دقائق)

1. اذهب إلى [supabase.com](https://supabase.com) وسجّل حساب مجاني
2. أنشئ مشروع جديد (اختر اسم + كلمة سر)
3. في **SQL Editor**، انسخ والصق محتوى `/supabase/migrations/schema.sql`
4. اضغط **Run** ✅

### الخطوة 2: التفعيل (1 دقيقة)

المشروع متصل بالفعل بـ Supabase!
فقط انتظر بضع ثوانٍ حتى يُفعّل الاتصال.

### الخطوة 3: جرّب التطبيق! (الآن)

1. افتح التطبيق
2. انقر "Sign up"
3. أدخل بريد إلكتروني وكلمة سر
4. ابدأ في إضافة المهام! 🎉

## 📱 استخدام التطبيق

### إضافة مهمة

**طريقة سريعة (Desktop):**
1. اكتب في حقل "Add a task quickly..."
2. اضغط Enter ✅

**طريقة كاملة:**
1. انقر زر "+" (Plus)
2. أدخل عنوان المهمة
3. (اختياري) أضف تعليق
4. (اختياري) حدد موعد نهائي
5. (اختياري) جدولها ليوم معين
6. (اختياري) اختر تصنيف
7. احفظ! ✅

### تنظيم المهام

**حسب التاريخ:**
- **اليوم**: مهام اليوم فقط

- **غير مجدولة**: بدون تاريخ محدد
- **جميع الأيام**: كل المهام

**حسب الحالة:**
- **الكل**: جميع المهام
- **غير مكتملة**: مهام نشطة
- **مكتملة**: مهام منتهية

**حسب التصنيف:**

## ❓ الأسئلة الشائعة

**س: هل البيانات آمنة؟**
ج: نعم! Supabase يستخدم Row Level Security - لا أحد يمكنه رؤية بياناتك غيرك.

**س: هل أحتاج للدفع؟**
ج: لا! Supabase Free Tier كافية لآلاف المهام ومئات المستخدمين.

**س: هل يعمل بدون إنترنت؟**
ج: حالياً لا، لكن يمكن إضافة Offline Mode لاحقاً.

**س: هل يمكنني تخصيصه؟**
ج: بالتأكيد! الكود مفتوح ومُوثّق. عدّل ما تشاء!

**س: أين يمكنني الحصول على الدعم؟**
ج: راجع README.md وملفات التوثيق الأخرى.

**س: كيف أحمّل المشروع؟**
ج: راجع DOWNLOAD_GUIDE.md للتعليمات الكاملة.

**س: كيف أنشره على domain خاص بي؟**
ج: راجع DEPLOYMENT.md للخيارات المتعددة.
